# Agent 附件与 EXIF 手动测试清单

本次自动验证只运行后端回归/接口测试与 Web 构建，不进行浏览器测试；Android 构建和设备验收由用户完成。

本目录集中保存附件与 EXIF 回归测试及手动验收说明。从 `backend` 目录运行：

```powershell
.venv/Scripts/python.exe -m pytest tests/agent_media -q
```

现有 `pytest` 配置会自动发现本子目录；运行完整后端测试仍使用 `python -m pytest`。

## 准备

- 更新后端并重启，保持单 worker；不需要新增数据库迁移或依赖。使用更新后的 Web 构建和 Android 安装包。
- 确认 COS 上传、读取和写入可用，日常模型支持工具调用，`MULTIMODAL_*` 配置支持看图，`SUPERBOX_ENABLED=true`。
- 准备含拍摄信息的 JPEG、PNG、WebP，以及 GIF/BMP 和一个小于 Android 现有 10 MiB 上限的视频。为验证 EXIF 服务限制，可额外准备大于 20 MiB 的图片在 Web 上传。
- 使用普通持久会话和测试用图片；记录测试前后积分，以便检查重连没有再次计费。

## 操作与预期

| 检查项 | 操作 | 预期结果 |
| --- | --- | --- |
| Web 上传入口 | 进入 Agent，分别选择图片、视频；另外测试拖拽和粘贴图片 | 显示预览，成功上传到 COS；Agent 模式保持开启 |
| Android 上传入口 | 进入 Agent，打开加号中的附件面板，选择图片或视频 | 可以选文件，上传后仍处于 Agent；发送只在上传完成后可用 |
| 模式切换 | 普通聊天上传图片后切入 Agent，再切回普通模式 | 待发送附件保持；上传过程中不可发送 |
| 失败与互斥 | 上传时模拟断网；同一条消息尝试混合图片和视频 | 显示失败并允许重试；已上传成功的附件保留；不允许混合图片和视频 |
| 图片理解 | 图片附带“描述这张图，并列出附件原始 URL” | 出现“图片内容理解”步骤；正文基于图片内容回答，URL 与原附件一致 |
| 仅图片发送 | 上传图片，不输入文字，直接发送 | 两端均可发送；Agent 默认概述图片内容 |
| 普通 AI URL | 普通聊天发送图片并问“给出这张附件的原始 URL” | AI 能给出原始 COS URL；图片输入仍正常使用 |
| 视频限制 | 视频附带“总结视频内容”；另测仅视频发送 | 正式正文明确“当前做不到视频内容分析”，仍提供原始链接；没有看图模型处理视频的成功步骤 |
| EXIF 读取 | 分别上传 JPEG、PNG、WebP，问“读取这张图的 EXIF，列出可写和只读信息” | 读取成功，标签来自实际接口；无标签的图片明确说明未发现 EXIF |
| EXIF 设置 | 说“将作者设为 ALChat，给出修改结果”，必要时明确标签为 `IFD0:Artist` | 编辑前查询/读取可写标签；正文有新图片预览与下载链接；新 URL 属于 COS，原图未覆盖 |
| EXIF 读回及删除 | 对结果说“读回作者字段”，再说“删除作者字段并给出结果” | 能处理本次生成结果及后续分支历史中的结果；读回为 ALChat，删除后字段消失 |
| 像素保持 | 下载编辑前后图片，使用本地 EXIF 工具或图片比较工具检查 | 原格式和图像内容保持；只改变 EXIF 元数据 |
| 只读及格式限制 | 尝试修改接口标记的只读字段；对 GIF/BMP/视频请求 EXIF 修改 | 不伪造成功；正式正文说明当前做不到及只读/格式原因 |
| EXIF 大小限制 | Web 上传大于 20 MiB 的图片，请求读取或编辑 EXIF | 上传保持原有行为；EXIF 正式说明超出 20 MiB 上限，无虚假下载结果 |
| 配置或服务故障 | 临时移除测试环境多模态配置，或使 Superbox/COS 不可用后提交相应请求 | 正式正文说明做不到及具体能力故障；恢复配置后新任务正常运行 |
| 刷新与重连 | 任务运行中刷新 Web/重进 Android 会话，完成后再次打开 | 步骤与正文恢复，无重复处理和重复计费；结果链接可访问 |
| 历史、编辑、重发及分享 | 对附件消息编辑重发，在当前分支追问原图/处理结果，再打开分享 | 附件和结果链接保留；当前分支可继续处理；分享展示已有结果和步骤，不重新执行任务 |
| 取消 | 图片或 EXIF 任务执行中停止 | 按现有流程进入取消终态，不继续发起后续模型或工具调用 |

记录客户端版本、图片格式/大小、任务 ID、提示词、正文、步骤错误码和结果 URL。重点检查“步骤失败但正文声称已完成”及“只在过程提示无法处理”。

视频分析、音频分析、非 EXIF 图片编辑不属于本次新增能力。供应商不支持的看图格式应给出明确失败，而不阻止文件按现有规则上传。
